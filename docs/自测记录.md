### 2. 评估逻辑（21 天模拟数据）

构造了 8 个事项，覆盖稳定、正常、懈怠、没做、补签、不适用、已完成、已删除八种情况，全部断言通过：

| 事项 | 场景 | 期望 | 实际 |
|---|---|---|---|
| A稳定 | 近 7 天全部 ✅ | 稳定坚持 / 应做 7 / 原始 7 | 一致 |
| B懈怠 | 前 5 天 ✅，最后 2 天空白 | 懈怠 / 原始 5 / 连续中断 2 | 一致 |
| C没做 | 连续空白 | 基本没做 / 原始 0 / 锁定 11 天 | 一致 |
| D正常 | 4 天 ✅、1 天 ✅、2 天 ❌ | 正常 / 原始 5 / 待补签 0 | 一致 |
| E补签 | 3 天 ✅、1 天 🩹、3 天空白 | 懈怠 / 原始 3 / 补签 1 / 待补签 3 | 一致 |
| H不适用 | 5 天 ✅、2 天 ➖ | 正常 / 应做 5 / 不适用 2 / 原始率 100% | 一致 |
| F完成 | 状态已完成，完成日 10-15 | 进入完成记录，持续 15 天 | 一致 |
| G删除 | 状态已删除，删除日 10-16 | 进入回收站，坚持 16 天 | 一致 |

汇总口径：昨日待补签 3 项、今日待办 6 项、稳定 1 / 正常 2 / 懈怠 2 / 基本没做 1，均与预期一致。

### 3. 补签

把 E 的 10-15 从空白改为 🩹 后重新计算：

- 原始完成仍为 3 天，原始率不变；
- 补签从 1 天变为 2 天；
- 含补签率从 4/7 提升到 5/7。

结论：补签只影响“含补签完成率”，不影响“原始完成率”。

### 4. 超期锁定

模拟“10-10 到 10-19 全部空白、补签窗口 7 天”：

- 近 7 天窗口内待补签 7 天；
- 超出窗口的 10-10、10-11 计为锁定 2 天；
- 10-12 刚好第 7 天，不计锁定。

### 5. 日期列自动增长

模拟表格最后日期停在 10-14、当前日期为 10-19：

- 运行后自动补到 10 列（10-10 至 10-19）；
- 最后一列表头为 10-19；
- 新日期列自动带上四态下拉与条件格式。

### 6. 表格被占用

- 评估仍可读取并计算；
- 自动跳过写回，提示“表格正被 Excel 打开，本次只读评估”；
- 原文件未被破坏。

### 7. 提醒与补发

| 模拟时间 | 状态 | 结果 |
|---|---|---|

### 8. 完成 / 删除 / 恢复

- 状态改为“已完成”且完成日期为空：自动填入当天日期，写入“完成记录”；
- 状态改为“已删除”且删除日期为空：自动填入当天日期，写入“回收站”；
- 把状态改回“进行中”：完成/删除日期被清除，事项回到评估列表。

### 10. 提示音

## 需要你在桌面确认的 3 件事

1. **气泡提醒**：双击 `测试提醒.cmd`，右下角应出现“每日打卡”气泡，点击可打开表格。  
2. **Excel 打开**：双击 `每日打卡`，表格应正常打开，今天这一列在最右边，三个示例事项可直接改名。  
3. **任务注册**：双击 `安装提醒任务.cmd`，看到“完成”即可；若失败，按窗口提示手动导入 `tasks\DailyCheckin.xml`。

## 已知限制

- 脚本全部使用相对路径，整个文件夹可以移动；放在固定目录即可。
- 脚本写回时会按模板重排表格，你额外添加的颜色、批注可能被重置；数据本身不受影响，且每次写回前自动备份。
- 表格被 Excel 打开时无法写回，会在下次打开或提醒时补上。
- 手机端默认只读（`report.html` 或 xlsx）；要手机直接打勾，需要额外配置 OneDrive 同步，并接受冲突风险。
- 系统气泡在部分 Win11 上会被通知设置或“专注助手”静默拦截。当前默认改为脚本自绘的右下角卡片（`notifyMode: "window"`），不依赖系统通知设置；想用气泡可改回 `"balloon"`。
